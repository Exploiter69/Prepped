# Prepped

**Prepped helps Indian engineering students practise placement and professional conversations, get specific feedback tied to their answers, and improve through repeated practice.**

Prepped is being restarted from a clean, evidence-led scope. The first version is a **local, text-based project-interview practice flow**. Voice is a later milestone gated on measured local-hardware feasibility. The project is not yet claiming validated placement outcomes or assessment accuracy.

## First MVP

One scenario: **Explain your project to a placement interviewer.**

The learner answers a few questions, receives feedback tied to their actual words, and retries using the same transparent checklist. The first version prioritises a working, testable learning loop over real-time audio, avatars, social features, institutional dashboards, or a large scenario library.

## Project constraints

- ₹0 mandatory spending: no required paid APIs, subscriptions, hosting, or usage-based services.
- Local-first development with a small, understandable architecture.
- Python + FastAPI, plain HTML/CSS/JavaScript, SQLite, and versioned JSON scenarios are the initial implementation choices.
- Optional local AI must not be required for the app skeleton or deterministic scenario tests to work.
- No claims of improved placement rates, validated skill scores, or learning effectiveness without evidence.
- GitHub is the source of truth.
